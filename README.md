This repository contains a complete network topology designed and simulated using Cisco Packet Tracer. The project demonstrates a secure, scalable, multi-site enterprise network with HQ and Branch locations, IoT integration, VPN connectivity, and routing using OSPF.

The topology includes:
Headquarters,
Multiple internal servers:
DHCP Server,
IOT Server,
Bckup Server,
AAA Server,
DC/DNS Server,
IoT devices connected through an access point,
Smart door, smart lights, smoke detector, temperature monitor, etc.
HQ Firewalls,
HQ Routers ,
HQ Multi-Layer Switch,
Branch Office.
Branch servers:
Web Server,
DHCP Server,
Backup Server,
DC/DNS Server,
Access Point for IoT tablet,
Branch routers and firewalls,
Branch multi-layer switch,
 Security & Connectivity,
Site-to-Site IPSec VPN Tunnel,
Connects HQ-FWL-1 to BRANCH-FWL-1
AAA authentication servers,
DMZ zones on both sites,
Routing,
OSPF Area 0 deployed across backbone.
MPLS cloud used to interconnect HQ and Branch routers
Purpose of This Project
This design demonstrates:
Enterprise-level network segmentation,
VPN-secured remote branch connectivity,
IoT device integration,
Server infrastructure deployment,
Implementation of OSPF and MPLS.
